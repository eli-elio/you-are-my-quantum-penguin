# you-are-my-quantum-penguin
A quantum game project developed for the Quantum Game Development course.

## How to Run the Game

### Requirements
- Python 3.10 or newer
- Pygame

### Installation
1. Download or clone this repository.
2. Open a terminal in the project directory.
3. Install Pygame:

   ```bash
   python -m pip install pygame
   ```
4. Run the game:

   ```bash
   python main.py
   ```

### Controls

| Key | Action |
|-----|--------|
| Arrow keys | Move the penguin |
| F | Talk to your partner / Continue dialogue |
| E | Catch fish |
| X | Apply the Pauli-X gate (costs 1 fish) |
| H | Apply the Hadamard gate (costs 2 fish) |
| Z | Apply the Pauli-Z gate (costs 3 fish) |
| TAB | Show / hide controls |

### Gameplay

Explore Antarctica as a quantum penguin searching for something special for your partner.

Catch fish to power quantum gates, switch between ice and underwater environments, and use quantum superposition and phase changes to solve puzzles.

**Current prototype:** The game includes exploration, fish catching, quantum gates, a split-screen superposition view, and a quantum phase barrier puzzle.
